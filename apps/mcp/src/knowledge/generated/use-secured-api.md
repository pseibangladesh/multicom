## useSecuredApi() Hook Reference

```ts
import { useSecuredApi } from "@/authentication";
```

`useSecuredApi()` wraps `useAuth()` and returns JSON helpers that send the **Better Auth session cookie** (`credentials: "include"`) and the storefront `pk_` key. There are no access tokens on the client.

| Member | Signature | Use |
|---|---|---|
| `getJson` | `(url) => Promise<any>` | GET returning JSON |
| `postJson` | `(url, body) => Promise<any>` | POST with JSON body |
| `putJson` | `(url, body) => Promise<any>` | full replace |
| `patchJson` | `(url, body) => Promise<any>` | partial update |
| `deleteJson` | `(url) => Promise<any>` | DELETE |
| `postForm` | `(url, formData) => Promise<any>` | multipart upload |
| `isAdmin` | `boolean` | session email is in ADMIN_EMAILS (UI hint only) |

Failed requests throw `Error("HTTP <status>: <server message>")`.

### Examples

```tsx
const { getJson, postJson, deleteJson } = useSecuredApi();
const apiBase = getApiBase();

const profile = await getJson(`${apiBase}/v1/me/profile`);
await postJson(`${apiBase}/v1/me/wishlist`, { productId: id });
await deleteJson(`${apiBase}/v1/me/wishlist/${id}`);
```

Hide an admin-only control:

```tsx
const { isAdmin } = useSecuredApi();
return isAdmin ? <Button onPress={translate}>AI translate</Button> : null;
```

### When not to use it

Public endpoints (product listing, categories) don't need a session: use `fetch()` or a React Query hook.

The AI-assisted features (review moderation, auto-translation) call `getJson` on `GET /v1/ai/parameters` to get `{ apiKey, model, url }`, then call `ai-client.ts` helpers from the browser.
